# 使用真实工具的业务验收需求

目标：根据测试客户编号，查询该客户信息和可用服务方案，输出结构化建议。

Agent 应自行查询当前 Dify 工具目录，找到至少两个真实业务工具；若没有相应工具，报告缺失能力，不生成虚构工具或 HTTP 地址。

验收要求：

- 保留每个已选工具的实际 provider 类型、ID、工具名和完整输入定义。
- 所有必填参数有明确来源，前一个工具的输出依据真实 output schema 引用。
- 无输出定义时通过最小测试草稿观察结果，不能推测字段。
- 正常测试客户返回结构化建议；客户不存在时给出明确说明。
- 包含输入不足、工具失败和会话隔离案例。
- Chatflow 输入不足时先追问，后续沿用已确认的客户编号。

测试数据由连接环境的负责人提供。此文件没有工具 ID、账户或客户数据，使用前填写你认可的测试编号和客观预期。
